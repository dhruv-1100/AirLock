# Benign image set

100 charts with no confidentiality marker, no temporal marker and no
internal vocabulary. Generated by `bench/make_images.py --benign --seed 1337`.

**Image FPR is reported separately from text FPR and is never folded into the
text denominator.** The two modalities have different base rates and different
failure modes; averaging them would hide both.

Any of these blocked is a false positive. The T3 grounding rule should force
BENIGN on all of them: no temporal marker, no confidentiality marker, no T1 hit
over the transcribed text means `override:"no_grounded_marker"`.
